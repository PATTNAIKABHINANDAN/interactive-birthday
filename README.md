# Interactive Birthday Website

A customizable React birthday website with animated scenes, photo galleries, a cake interaction, a lock screen, a letter section, optional video and music, and a final message scene.

## Customize

Edit `src/data/birthdayData.js` to replace the placeholder name, age, messages, captions, letter and lock code.

Replace the placeholder files in `public/assets/photos/` with your own images. Optional media can be added at:

- `public/assets/videos/special-memory.mp4`
- `public/assets/music/music.mp3`

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Tech stack

React, JavaScript, CSS, Vite and Framer Motion.
